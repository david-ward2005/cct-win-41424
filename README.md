## About CCT

CCT is a church calendar widget designed for Wix sites that need a structured calendar presentation with Orthodox calendar content. It focuses on displaying daily information in a compact and readable way, making it easier to surface saints, notes, and marked dates inside a website layout.

The widget is suited for projects that need multilingual calendar content without a heavy setup. It can detect CSV data sources automatically, which helps streamline content updates and keeps the calendar data organized across different language versions.

Yes. Day cards can include saints and notes as part of the calendar display.
